# Веб-застосунок для інтерактивної симуляції та моделювання фізичних процесів. Фронтенд складова

Індивідуальний STEM-проєкт з освітнього компонента **«Розробник фронтенду програмних систем» (РФПС)**.

## Про проєкт

Фронтенд симулює в реальному часі три фізичні процеси на HTML5 Canvas:

1. Балістичний рух у полі тяжіння
2. Пружні зіткнення кульок
3. Гармонічний маятник

Можливості: редагування параметрів під час симуляції, візуалізація векторів швидкості та сил, телеметрія з журналом і статистикою енергії, експорт сцени (JSON), телеметрії (CSV) та знімка полотна (PNG), імпорт сцени з валідацією, профіль дослідника в `localStorage`, світла й темна теми, гарячі клавіші Space (старт / пауза) та R (скидання).

## Технологічний стек

React 18, TypeScript (strict), Vite, Tailwind CSS 3, Lucide Icons, HTML5 Canvas API, Vitest + Testing Library.

## Запуск

Потрібен Node.js 20 або новіший.

```bash
git clone https://github.com/GreyA-A/physics-sim-frontend.git
cd physics-sim-frontend
npm install
npm run dev
```

Застосунок відкриється на `http://localhost:5173`.

| Команда | Призначення |
|---------|-------------|
| `npm run dev` | Сервер розробки |
| `npm run build` | Перевірка типів і production-збірка в `dist/` |
| `npm run preview` | Локальний перегляд збірки |
| `npm run typecheck` | Перевірка типів TypeScript |
| `npm run lint` | ESLint |
| `npm run test` | Усі тести Vitest |
| `npm run test:watch` | Тести в режимі спостереження |
| `npm run test:coverage` | Тести зі звітом покриття та перевіркою порогів (95 / 90 / 95 / 95) |

## Структура

```text
src/
  components/   презентаційні та контейнерні компоненти
  context/      SessionContext (профіль і тема)
  engine/       фізичне ядро та відмальовування Canvas (без React)
  hooks/        гарячі клавіші
  reducers/     скінченний автомат симуляції (useReducer)
  types/        доменні типи
  utils/        валідація, сховище профілю, експорт, статистика
  __tests__/    модульні, компонентні та наскрізні тести
docs/diagrams/  діаграми Mermaid
```
