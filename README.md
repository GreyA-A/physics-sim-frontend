# Веб-застосунок для інтерактивної симуляції та моделювання фізичних процесів. Фронтенд складова

## Про дисципліну

РФПС передбачає засвоєння сучасних бібліотек і фреймворків для розробки фронтенду, який відповідає вимогам адаптивності, кросбраузерності, захищеності та зручності користувацького досвіду.

## Опис проєкту

Фронтенд застосунку, що симулює три фізичні процеси в реальному часі на HTML5 Canvas:

1. Балістичний рух у полі тяжіння
2. Пружні зіткнення кульок
3. Гармонічний маятник

Можливості: редагування параметрів під час симуляції, візуалізація векторів швидкості та сил, телеметрія, експорт сцени (JSON), телеметрії (CSV) та знімка Canvas (PNG).

## Технологічний стек

React 18, TypeScript, Vite, Tailwind CSS, Lucide Icons, HTML5 Canvas API, Vitest.
